# Morgan Hill Solicitors — Maintenance Page

A simple "under maintenance" holding page for the Morgan Hill Solicitors website.

Built as a static page with no dependencies or build step — just open `index.html` or drop the files onto any web host.

## Features

- Branded to match the firm's logo colours (crimson `#A82A2E`, charcoal `#4D3F3F`)
- Responsive layout for desktop and mobile
- Automatic light and dark mode
- Animated progress indicator, disabled for users who prefer reduced motion
- `noindex` tag so search engines don't index the maintenance state

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page markup |
| `styles.css` | Styles and brand colour variables |
